# 第 32-34 关设计

## 设计范围

第 32-34 关只使用行星引力，不再加入陨石或尘埃。三关分别强调借力转向、双井 S 弯和绕行进入小终点，最多部署 8 枚炸弹。

## 第 32 关：角落护卫星

### 布局

- 地图 `390 x 844`，出生点与第一关相同。
- 右上角四分之一圆终点，半径 `118`。
- 行星位于终点下方偏右 `(292, 228)`，半径 `50`，`μ = 980000`。

### 设计意图

直飞会被右侧行星的引力拉入表面。玩家需要先获得向左的切向速度，从行星左侧掠过，再利用引力把轨迹弯向右上角。过近会撞星，过早右转同样会撞上护卫星。

### 验证路线

1. 在 `(245, 680)` 部署炸弹，飞船上升至 `y <= 680` 时引爆，向左离开中轴。
2. 在 `(0, 220)` 部署炸弹，飞船上升至 `y <= 220` 时引爆，在近星点后修正进入角落终点。

## 第 33 关：交错双星

### 布局

- 地图高度 `1200`。
- 下星偏右 `(272, 900)`，半径 `54`，`μ = 760000`。
- 上星偏左 `(118, 380)`，半径 `50`，`μ = 720000`。
- 右上角四分之一圆终点，半径 `110`。

### 设计意图

直线被下星捕获。只向左躲会进入上星引力井。需要先从下星左侧通过，再向右绕过上星，把双井当成连续转向点。

### 验证路线

1. 在 `(228, 1040)` 部署炸弹，飞船上升至 `y <= 1040` 时引爆，绕过下星。
2. 在 `(80, 560)` 部署炸弹，飞船上升至 `y <= 560` 时引爆，转向上星右侧并进入角落终点。

只使用第一枚炸弹会撞上上星。

## 第 34 关：井上停泊

### 布局

- 地图 `390 x 844`，出生点与第一关相同。
- 中央行星 `(195, 292)`，半径 `64`，`μ = 1100000`。
- 行星上方自闭合圆形终点 `(195, 90)`，半径 `40`，与行星表面留有间隙。

### 设计意图

终点在行星正上方，直飞必然撞星。玩家必须先离开中轴绕行，再在近星点之后把飞船送入上方小圆；引力会持续把轨迹拉回行星，过晚回正会错过终点并越顶。

### 验证路线

1. 在 `(228, 660)` 部署炸弹，飞船上升至 `y <= 660` 时引爆，离开中轴。
2. 在 `(30, 560)` 部署炸弹，飞船上升至 `y <= 560` 时引爆，保持绕行速度。
3. 在 `(0, 210)` 部署炸弹，飞船上升至 `y <= 210` 时引爆，转入上方圆形终点。
