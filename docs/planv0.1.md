# BoomDash v0.1 更新计划

## 1. 版本目标

本次更新在第一关核心玩法的基础上，加入第二关、开始界面和关卡选择流程。第二关只扩大纵向地图距离，不加入障碍物、风场、重力、敌人或其他会改变核心玩法的系统。

本版本的主要目标：

1. 玩家首次进入游戏时看到统一风格的开始界面。
2. 玩家可以从关卡选择界面直接进入所有当前已登记关卡。
3. 第一关成功后可以直接进入第二关。
4. 第二关使用约两倍于第一关的纵向距离。
5. 玩家可以通过上下拖动浏览第二关完整地图。
6. 飞行时相机自动跟随飞船，让终点始终可以被观察到。
7. 画面只保留终点半椭圆，不显示起点椭圆。

## 2. 现状和约束

### 2.1 现有基础

- 游戏使用 Vite、TypeScript 和原生 Canvas 2D。
- 逻辑视口为 `390 x 844`，竖屏优先。
- 飞船、炸弹、爆炸和结果状态已经由固定时间步模拟。
- 第一关已有部署、发射、引爆、暂停、重试和重新部署流程。
- 当前视觉使用深色太空背景、青色、洋红色、荧光绿色和橙色反馈。

### 2.2 本次不改变的内容

- 不改变炸弹冲量计算方式。
- 不改变飞船惯性飞行方式。
- 不增加障碍物和路线限制。
- 不限制炸弹与终点的距离。
- 不加入关卡解锁条件。
- 不改变第一关的逻辑视口大小。

## 3. 关卡数据设计

### 3.1 视口与世界

`390 x 844` 继续表示设备上的逻辑视口。关卡定义增加 `worldHeight`：

- 第一关：`worldHeight = 844`。
- 第二关：`worldHeight = 1688`。

屏幕尺寸、Canvas 缩放和 HUD 布局仍然基于视口尺寸。炸弹、飞船和终点坐标使用世界坐标。

### 3.2 第二关位置

第二关沿用第一关的横向布局：

- 起点中心约为 `(195, 1654)`。
- 终点中心约为 `(195, 34)`。
- 终点半椭圆半径继续使用 `rx = 125`、`ry = 58`。
- 第一关和第二关使用相同的炸弹数量、爆炸半径和速度上限。
- 第二关时间限制适当增加到 `24 秒`，使增加的飞行距离可通过现有物理完成。

起点数据仍用于飞船出生位置，但渲染层只绘制 `goal`，不绘制 `start` 椭圆。

### 3.3 关卡目录

新增统一关卡目录，当前登记：

- `SECTOR 01`
- `SECTOR 02`

关卡选择界面从目录生成按钮。开发阶段不设置 `locked`、解锁条件或完成前置条件。以后新增关卡时，只要加入目录，就可以直接从选择界面进入。

## 4. 相机和滚动交互

### 4.1 相机范围

相机维护一个 `offsetY`：

```text
0 <= offsetY <= worldHeight - viewportHeight
```

第一关的最大偏移为 `0`，所以现有画面行为不变。第二关的最大偏移为 `844`。

### 4.2 部署阶段

- 进入第二关时相机默认停在地图底部，先显示飞船出生位置附近。
- 在空白区域上下拖动时滚动地图。
- 向上拖动手指会浏览更靠上的地图区域。
- 鼠标滚轮在桌面端执行同样的滚动操作。
- 点击空白区域仍会在准确的世界坐标放置炸弹。
- 点击并拖动炸弹只移动炸弹，不移动相机。
- 地图拖动结束后不会误放置炸弹。
- 相机偏移始终被限制在地图范围内，不会显示世界外区域。

### 4.3 飞行阶段

- 发射时相机重置到地图底部，确保能看到飞船开始飞行。
- 飞船上升后，相机根据飞船位置向上跟随。
- 相机跟随不修改物理状态和飞船坐标。
- 炸弹引爆、爆炸特效、飞船尾迹和星点都使用同一世界坐标变换。
- 到达终点或失败后保留最终相机位置，方便观察结果。

### 4.4 坐标转换

指针先转换为视口逻辑坐标，再通过相机偏移转换为世界坐标：

```text
worldX = viewportX
worldY = viewportY + offsetY
```

炸弹命中检测、炸弹放置和炸弹拖动均使用世界坐标。

## 5. 开始界面和关卡选择

### 5.1 开始界面

开始界面保持当前的深色矩形面板和霓虹边框风格，包含：

- `BOOMDASH` 标题。
- `START` 主按钮，直接进入第一关。
- `SECTORS` 按钮，进入关卡选择界面。

开始界面显示时隐藏 HUD、部署栏、炸弹栏和调试信息，避免与菜单内容重叠。

### 5.2 关卡选择界面

关卡选择界面由关卡目录动态生成：

- 每个关卡都有可点击按钮。
- 当前所有关卡均可用，不显示锁定状态。
- 已有最佳时间时显示最佳时间，没有时显示 `BEST --`。
- `BACK` 返回开始界面。

### 5.3 结果界面流程

- 第一关成功：显示 `NEXT SECTOR`，直接进入第二关部署阶段。
- 第二关成功：不显示不存在的下一关按钮。
- 失败和成功都保留 `RETRY`、`REDEPLOY` 和 `SECTORS`。
- `RETRY` 保留炸弹部署并重置飞船。
- `REDEPLOY` 清除炸弹并回到当前关卡部署阶段。
- `SECTORS` 返回开始界面，之后可以选择任意当前关卡。

- 相机在高世界中从底部开始。

- 视口坐标可以正确转换为世界坐标。
- 相机跟随飞船时保持边界限制。
- 第二关世界高度和起终点距离符合约两倍距离要求。
- 第二关飞船越过世界底部时失败。
- 第一关原有的炸弹、暂停、生命周期和回放测试继续通过。

### 7.2 端到端测试

- 首次进入显示开始界面。
- `START` 可以进入第一关。
- `SECTORS` 可以查看第一关和第二关。
- 第一关和第二关按钮都处于可用状态。
- 进入第二关时 HUD 显示 `SECTOR 02`。

## 8. 验收标准

1. 页面首次打开不会直接进入游戏，而是显示开始界面。
2. 点击 `START` 后可以正常进入第一关部署阶段。
3. 关卡选择界面中第一关和第二关都可直接点击，没有锁定或限制。
4. 第一关成功后可以通过 `NEXT SECTOR` 进入第二关。
5. 第二关的完整地图高度约为第一关的两倍。
6. 第二关部署时可以上下滑动浏览起点到终点之间的完整地图。
7. 第二关飞行时相机会自动跟随飞船。
8. 起点椭圆不显示，终点椭圆继续显示并在成功时增强亮度。
9. 炸弹在滚动前后都保持正确的世界坐标和命中关系。
10. 现有第一关玩法、样式和测试不发生无关回归。
