# 第 21-22 关设计

## 星际尘埃机制

- 尘埃区域使用与终点、陨石相同的结构化世界几何；渲染、飞船接触判定和调试显示复用同一份区域数据。
- 飞船接触尘埃后，固定时间步模拟按区域的 `dragPerSecond` 对速度施加指数阻尼；阻尼只降低速度大小，不改变当前方向。
- 多个尘埃区域重叠时阻尼相加。尘埃不会直接导致失败，飞船离开区域后立即恢复无阻尼惯性飞行。
- 尘埃使用灰色半透明填充、灰色细边框和细小灰色颗粒，与红色陨石禁入区明确区分。
- 第 21 关开始前展示一页机制教程，说明飞船会在尘埃中持续减速，需要预留炸弹补充速度。

## 第 21 关：中央尘埃带

### 布局

- 世界尺寸为 `390 x 844`，飞船从底部中央出生。
- 顶部中央设置 `160 x 80` 的圆角矩形终点。
- 出生点与终点之间设置 `274 x 155` 的圆角矩形尘埃带，阻尼为 `0.45/s`。
- 本关没有陨石，最多部署 8 枚炸弹。

### 设计意图

本关单独介绍尘埃减速。直线发射可以安全进入尘埃，但初始速度不足以穿过整片区域，飞船会在带内逐渐接近静止并最终超时。玩家需要把至少一枚炸弹留到进入尘埃后再引爆，用爆炸冲量补足穿越区域和抵达终点所需的速度。

### 验证路线

1. 在 `(195, 470)` 部署炸弹。
2. 直线发射，飞船上升至 `y <= 470` 时引爆。
3. 爆炸从尘埃内部补充向上速度，飞船穿出尘埃并进入顶部中央终点。

### 典型失败

- 不引爆炸弹时，飞船在尘埃带内减速并因超时失败。
- 过早引爆会使新增速度在尘埃中消耗过多，仍可能无法穿出。
- 过晚引爆会浪费大量时间，降低评分或直接超时。

## 第 22 关：同心尘埃弧

### 布局

- 世界尺寸为 `390 x 844`，飞船从底部中央出生，终点为左上角与地图边界闭合的四分之一圆区域。
- 以地图左上角为圆心设置三层互不重叠的四分之一圆弧尘埃带，内外半径分别为 `78–105`、`160–202` 和 `346–380`。
- 三层尘埃的阻尼均为 `0.32/s`，本关没有陨石，最多部署 8 枚炸弹。

### 设计意图

玩家需要同时管理方向与剩余速度。直线飞行会穿过外层和中层尘埃，但无法进入左上角终点，最后在中层尘埃附近减速超时。推荐路线使用前三次爆炸形成连续向左上方的弧线并补充穿层速度，最后一次爆炸修正入射方向，进入最内层尘埃后的角落终点。

### 验证路线

1. 在 `(206.01, 789.95)` 部署炸弹，飞船上升至 `y <= 742` 时引爆。
2. 在 `(184.05, 590.60)` 部署炸弹，飞船上升至 `y <= 572.5` 时引爆。
3. 在 `(129.65, 322.27)` 部署炸弹，飞船上升至 `y <= 306` 时引爆。
4. 在 `(57.15, 159.98)` 部署炸弹，飞船上升至 `y <= 158` 时引爆，修正后进入左上角终点。

### 典型失败

- 直线发射会沿 `x = 195` 穿过部分尘埃层，但无法进入左上角终点并最终超时。
- 前两次爆炸向左分量不足会错过角落，分量过大则会从左边界越界。
- 最后一次修正过早会偏离终点，过晚则会在内层尘埃中损失过多速度。
